# 实现验证记录

日期：2026-09-18。目标：忽略积分领取，完成 pol2api 的任务提交、查询、对外调用与 ak2api 风格的管理界面。

## 实现范围

- 已授权 Cookie/CDP 会话导入、账号池、代理分配、并发控制、余额检查及下游账号同步入口。
- 素材下载、图片校验、音视频 ffprobe 元数据解析、签名上传和素材登记。
- 9 个约定模型别名、4 个上游名称、素材引用归一化、实时模型配置校验和完整参数动态报价。
- 异步任务队列、同步等待、上游任务轮询、视频结果获取、任务审计、查询恢复、显式失败重试。
- 任务管理、账号管理、模型测试调用、设置持久化、实际消耗参考、接入文档。
- Videos、Responses 兼容包装、通用任务 API，独立管理/API/同步鉴权。

## 自动化检查

44 项 pytest 测试通过；Ruff、JavaScript 语法检查通过。关键行为包括：

- 提示词引用匹配、模型分辨率、素材数量、参数边界与外部输入校验。
- tRPC 请求封装、余额汇总、报价折扣、任务 ID 和结果解析。
- 创建/查询/结果跳转、鉴权、账号接口凭据脱敏与设置保存、重启后恢复（含小数、布尔值和清空文本）。
- 余额不足不提交；接受任务后本地保存失败不重发；网络超时和未知响应不重发。
- 已取得任务 ID 的重启恢复和超时重试只查询原任务，不再次扣减本地余额。
- 重启时处于提交中的任务转为待人工核对，不自动回放 POST。

这些测试使用可控上游替身，不代表所有模型已完成真实付费生成。

## 实际环境验证

- 使用原生 CDP 读取用户已打开的浏览器会话；未使用 Playwright。
- 当前会话、余额及项目可用；图片上传与动态报价成功，提示词引用与素材名称匹配。
- 混合素材实测通过：图片、2 秒视频、约 5.15 秒音频均完成下载、元数据解析、签名上传及登记；完整请求报价原价 17、折后 6，三种引用全部匹配。单图测试原价 20、折后 8，证实需要按完整请求动态询价。
- 通过新客户端查询此前手动生成的 Mini 480p 任务，状态成功；返回 864×496、4.096 秒且含音轨的视频。
- 控制台通过原生 CDP 检查：账号和模型加载、设置保存及还原、测试调用窗口、接入文档、任务详情，未发现页面脚本错误。
- 手动捕获的成功任务被明确标注为历史导入样本，可在本地控制台查看。
- 最终代码重启后健康检查通过；使用本地 API 密钥验证 Videos、Responses 和通用任务查询成功，视频内容入口返回 307；未鉴权访问返回 401，错误生成参数返回 422。

账号余额为 2 积分，测试报价为 6–8 积分，未发起新的付费生成。2.0 标准、Fast、Mini 720p、2.5 和其他分辨率能力来自服务端 manifest；尚未逐组合实测生成。

本地服务端口 8798，数据和凭据位于被 Git 忽略的 `.env`、`data/`、`output/`。原始监听文件保留在原工作区忽略目录。脱敏协议研究资料在 `docs/research/`。
